# Face Attendance Hub

A professional and modern attendance management system using face recognition.

## Features

- **Employee Registration**: Register user photos, face descriptors, and details.
- **Attendance Kiosk**: Real-time face recognition for check-in and check-out time logging.
- **Records & Analytics**: View daily reports, attendance status, and duration.

## Development

```sh
bun install
VITE_API_BASE_URL=http://localhost:5000 bun run dev
```

The frontend expects the local Flask backend to be running on port 5000.
